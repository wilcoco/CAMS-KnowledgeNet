# 14 — 사람 중심 · 근거와 종합 (분기 숙고)

> **상태:** 숙고/방향 합의, *최종 분기는 사용자 결정 중*. 최근 대화(검색·RAG·종합 vs
> 우리 흐름, 사람 중심)를 보존. 제1원리는 [`00-epigraph.md`](00-epigraph.md).

## 1. 두 흐름 — 경쟁이 아니라 *겹쳐 쌓임(nest)*
```
검색 → 링크 → 정리   = 답을 *만드는* 법      (LLM Wiki, 근거)
평가 → 보강/반론/후속 = 답을 *정련하는* 법    (우리, 판단)
```
합치면 우리 흐름의 *첫 단계 안에* LLM Wiki가 들어간다:
**(검색·근거) → AI 답(인용) → 평가 → 보강/반론/후속.**

## 2. 흔들리지 않는 구분
- **출처 = 근거(grounding)** — 검증가능성·환각 방지.
- **발자국 = 판단(judgment)** — 권위·진실 결산.
- 직교·상보. 좋은 길 = *근거 있고 + 두루 밟힌* 길.
- **출처는 배심원에게 줄 *증거*지 *판결*이 아니다.** 어느 근거 있는 답이 옳은지는 여전히
  *평가(발자국)* 가 결산 → 평가-앵커 인식론은 안 흔들리고 검색은 *돕는다.*

## 3. 사람 중심 (핵심 선)
| | 사람 | AI |
|---|---|---|
| **LLM Wiki** | 크롤러(소스 수집·질문) | **종합·분석가 = 지식의 *저자*** |
| **우리** | **판단자·길 내는 자 = *저작*** | 정찰병·횃불(보조·초안) |

- LLM Wiki = *사람이 긁어온 걸 AI가 종합해 지도를 그림*(지도 = AI 합성물).
- 우리 = **사람이 걸어 남긴 발자국이 곧 지도.** AI는 *횃불*이지 *지도 제작자*가 아니다.
  *今日我行跡 — 내(사람) 자취가 길이 된다.*
- 구체: **AI 초안 = 보조바퀴**(빈 페이지 활성화 에너지↓), **권위·저작은 사람의
  평가·보강·정정이 부여.** 노드가 성숙할수록 *사람 판단이 AI 초안을 압도*해야(사람 기여
  비중 = 성숙도). 사람의 *이유·판단* 이 substance, AI는 scaffold.
- **반-AI 아님:** AI는 *고된 일*(초안·검색·요약), 사람은 *판단* — **AI 산출물은 늘 사람
  평가에 종속.**

## 4. 답하기 — *지형 따라 라우팅*
"항상 RAG vs 항상 생성"이 아니라:
- 질문이 **이미 두루 밟힌 길에 닿으면** → 그 길을 쓴다(내부 RAG·인용, 고신뢰).
- **새 지형이면** → AI가 초안 길을 낸다(생성) → 밟히고 평가됨.
- 답은 다시 *노드=새 길*이 되어 뒷사람이 밟음(今日我行跡 遂作後人程).

## 5. 종합 — *결정문*이 아니라 *지형도*
LLM Wiki 종합 = 단일 산문(이견을 매끈히 지움) → 우리 원리와 충돌, *AI-저자화* 위험.
우리식 종합 = **발자국이 그린 지형도**: 따뜻한 땅 길(채택) + 다투는 길(fork) + 막힌
길(정정-환수) + 미답 지형(열린질문). *파생·on-demand*(노트12 벽 회피). AI는 *렌더*만,
내용 저작 X. (AI 합성은 상관된 걸 평균 내 mush로 만들어 *두루*를 죽임.)

## 6. 콜드스타트가 순서를 뒤집는다
- **내부 RAG**는 커먼즈가 풍부해야 값이 남 → *나중* 강해짐.
- **웹 근거**는 *초기* 답 품질을 세움 → 초기 웹, 성숙하면 내부 RAG로 무게중심 이동.
- 닭-달걀: 좋은 답 → 사람 모임 → 평가 → 내부RAG 쓸 만해짐.

## 7. 진짜 분기 + 메타 경계
- **커먼즈-우선 vs 답-우선.** 답-우선으로 기울면 Perplexity·LLM Wiki 앞마당에서 패배.
  **우리 해자 = "판단된·근거 있는·이견 보존된" 지식이지 *가장 빠른 답*이 아니다.**
- **메타 함정:** 써보기 전 과설계 = *얼어붙는 것*. 핵심 루프(묻기→답→평가/발자국→탐색)를
  *웹 근거로 첫 답만 살려* 빨리 굴리고, **실제 발자국이 가르치게.**

## 8. 잠정 기울기 (결정 아님)
1. 아키텍처 유지(커먼즈-우선). 답-엔진으로 안 감.
2. 첫 단계 *근거만* 강화 — 초기 웹, 성숙 후 내부 RAG, 지형 따라 라우팅.
3. 종합 = 이견 보존 지형도, *파생 렌즈*로 나중.
4. 덜 짓고 더 굴려 실제 발자국을 받자.
