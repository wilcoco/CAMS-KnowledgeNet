# 09 — 좌측 트리 탐색기: 위치를 보여주는 디렉토리

> **상태:** 결정 완료 → 구현(1차). 노트 06/08의 **우측 트레일**을 *대체하지 않고*
> **위치 감각**을 보강한다.
> **한 줄:** *지식 그래프를 좌측에 **Root→서브 디렉토리**(IDE 탐색기)로 펼쳐, 클릭하면
> 그 노드로 가고, 어디를 읽든 트리가 **"너 여기 있다"**를 항상 비춘다.*

---

## 1. 왜

우측 슬라이딩 트레일(노트 06)은 *한 줄의 읽기 경로*는 잘 보존하지만, 데이터의 **그래프
구조**(부모·자식·형제 가지·백링크)와 **내 위치**를 못 보여준다 — 필름스트립일 뿐이다.
재귀로 깊이 들어갈수록 "내가 전체에서 어디인지"가 사라진다.

해결: **같은 구조를 그대로 비추는 위치 지도.** 우측으로 무한정 늘리는 대신, 좌측
디렉토리가 전체 숲을 들고 있고 현재 노드를 강조한다(Windsurf/VSCode 탐색기식).

## 2. 모양

```
좌측 = 지식 트리(탐색기)        중앙 = 포커스 리딩(노드 깊게 읽기)     우측 = 점수·경제
  Root 개념 A                     ┌──────────────────────────┐
   ├─ 후속질문                    │  (클릭한 노드의 답+스레드)   │
   ├─ ↳ 맥락 펼침                 └──────────────────────────┘
   └─ 보강
  Root 개념 B  ← (지금 여기)
```

- **트리 = parent_id 계층만** (Root→스레드/펼침 자식). 위키링크는 *그래프 간선*이라
  트리 자식이 아니다(순환 방지) — 연결/백링크는 중앙 패널에서 그대로 재진입.
- **클릭 = 그 노드로 이동**(중앙 포커스). **트위스트(▸/▾) = 펼치기/접기.**
- **위치 동기화:** 어느 경로로 노드를 열든(트리·링크·검색·트레일 포커스) 트리가
  그 노드의 조상을 펼치고 **현재 항목을 강조**하며 스크롤해 보여준다.

## 3. 1차 범위(이번 구현)

- 백엔드 `GET /api/tree?space=` — 가시 노드의 숲을 중첩 JSON으로
  (`id,title,kind,anchor,authority,children`). Root는 권위순 정렬.
- 좌측 aside 최상단에 `#tree` 탐색기 + 새로고침. 접힘 상태는 클라이언트가 보존.
- `focusPane`에서 활성 노드 → `syncTree`(조상 펼침·강조·스크롤). 노드 생성/평가 후
  `loadTree`로 갱신.
- **트레일은 유지**(가산적). 우측 확장과 좌측 위치 지도가 공존 — 다음 단계에서
  "제자리 이동 우선"으로 더 옮길지 결정.

## 4. 다음 단계(미구현, 노트로만)

- **점유율(노트 B):** 같은 트리/그래프에 *내 노드 하이라이트* → 지식 공간 점유율이
  곧 눈에 보인다. 트리 인프라 재사용.
- **그래프 미니맵:** 트리로 부족하면(교차링크 多) 이웃 그래프(SVG/canvas)로 승격.
- **제자리 이동:** 링크 클릭을 우측 누적 대신 중앙 제자리 전환 + 트리 위치로.
