# 16 — 시멘틱 릴레이션: 판단되는 링크 타입

> **상태:** 결정 → 구현(1차). 참조: [`../refs/qaqa-sibling-project.md`](../refs/qaqa-sibling-project.md) 문서 C.
> **한 줄:** *링크(`[[제목]]`)는 기본 무라벨(관련)로 영원히 마찰 0. 원하는 사람이 **칩 한 번**으로
> 타입(상위/하위/전제/대립)을 달고, **확인(밟음)된 만큼** 그 타입이 신뢰를 얻는다.*

## 1. QAQA 검토 결론 (대조)

- **담화관계 층(7종 태그)은 불채택** — 우리는 *행위 자체가 관계*다:
  보강=근거·명확화, 정정(fork)=반박, 후속=더깊게, 발자국=검증. 태그(정규식)는 QAQA
  스스로 "불안정" 인정. *메타데이터보다 행위가 단단하다.*
- **구조관계 어휘만 빌린다** — generalization/specialization/prerequisite/conflicting(SKOS).
  13종 풀 택소노미는 야후 노동(아무도 안 닮) → **4+1로 압축.**
- **자동 확정 배척** — QAQA는 AI 태그+코사인(≥0.65)으로 관계를 *자동 생성·확정*(판단층
  없음). 우리 룰: **AI/휴리스틱은 제안만, 사람 확인(발자국)이 채택**(노트 14·15).

## 2. 타입 — 4+1

| 타입 | 뜻 | SKOS/QAQA 대응 |
|---|---|---|
| **관련** (기본) | 무라벨 — 지금의 `[[링크]]` 그대로 | related |
| **상위** | 대상이 이 개념의 일반화/포함 | broader / generalization |
| **하위** | 대상이 이 개념의 구체화/사례 | narrower / specialization·extension |
| **전제** | 대상을 먼저 알아야 함 (학습 경로) | prerequisite |
| **대립** | 대상과 충돌·반례 (개념 *간* 긴장 — fork는 개념 *안*) | conflicting / counterargument |

## 3. 동작 룰 (사람 중심·무마찰)

1. `[[제목]]` 타이핑·드래그 링크는 **변경 없음** = 관련. 새 문법 없음.
2. 패널의 연결 목록에서 **타입 칩 탭** 한 번 → 타입 지정 = **첫 확인자.**
3. 같은 타입을 다른 사람이 또 탭 → **확인 +1** (관계의 두루). 다른 타입을 탭하면 경쟁
   타입으로 병기 — *관계도 모순 공존 + 다수 확인이 앞으로* (노트 12 원칙 그대로).
4. AI 제안(후속): 링크 생성 시 타입을 *흐리게 제안*만, 확인 전엔 미채택.

## 4. 데이터 모델 (하위호환)

- `Node.links: list[str]` **유지** (기존 데이터·내보내기·파서 무손상).
- 추가: `Node.link_rels: dict[slug → {type → [확인자…]}]` — 타입은 *덧칠*.
  직렬화는 JSON 필드 하나(스냅샷·pg 공통), 없으면 빈 dict.
- API: `POST /api/nodes/{id}/relate {target, rel, author}` = 타입 확인(토글 아님, 누적).
  뷰: `outlinks[].rel`(다수 확인 타입)·`rels`(전체 집계) 포함.

## 5. 산출 효과

- 트리 `→ 참조`·패널 연결에 *왜 연결됐는지*가 붙음.
- **전제** → "이걸 먼저" 학습 경로의 토대. **대립** → 개념 간 긴장이 지형도(노트 14 §5)에.
- 관계 확인 수 = 관계의 신뢰(두루) — 노드와 같은 인식론을 간선에도.
