# 22 — 무결성·비용 수리 묶음 (노트 21 백로그 전체 구현)

> 노트 21 대규모 시뮬레이션이 지적한 것 전부 + 노트 18 잔여(P2·P3)를 설계·구현.
> 테스트 164개(신규 6) 통과, 시뮬 재실행으로 효과 실측. 원칙 불변: **판정은
> 사람, 시스템은 신호만 / 새 입력 강요 없음.**

## 1. 스텁 링크 안목 파밍 차단 — `tree._finalize` ★최우선

- **문제(실측):** 흔한 개념 스텁을 가리키는 모음글 12쪽만으로 허브 105 vs
  큐레이터 중위 28 — 안목 보드 압살.
- **수리:** 위키링크 적립은 대상이 **실제 글일 때만**. 링크가 방금 만들어 낸
  빈 스텁을 가리키는 건 안목이 아니다 — **스텁이 승격된 뒤의 링커부터 적립.**
- **효과(시뮬 재실행): 파머 허브 105 → 0.00, 안목 top10 큐레이터 2/8 → 8/8.**
  (부수: 저자의 자동 스텁 링크 인플레도 함께 제거 — 보드가 진짜 안목으로 채워짐)

## 2. 링 상호 허브 상속 감액 — `scoring.link(kin=)` (결정로그 미해결 1 해소)

- **문제:** 링이 서로 밟아 서로의 안목을 키우는 폐회로는 읽기 렌즈(두루)가 못
  누른다 — 적립단의 잔여 구멍.
- **수리:** 새 발자국자와 **같은 무리**(두루 군집과 동일 판정, `tree.kin_of`)인
  이전 발자국자에게 가는 안목 상속은 **1/|무리|** 로 감액. 무리 밖 독립 검증
  상속은 그대로. 엔진은 판정을 받기만(저장-무관 원칙 유지).
- 새 휴리스틱이 아님 — 두루와 *같은 신호*의 쓰기단 적용.

## 3. 생성 쿼터 — `NIGHTWISH_ASK_QUOTA` (노트 19 §2-③ 구현)

- **문제(실측):** 고유 질문 100건 난사가 전부 초안 생성 — 실LLM이면 비용 무방비.
- **수리:** *새 생성*(ask 초안·후속·펼침·스텁 채우기·질의 AI답)만 사용자·일 단위
  N건, 초과 시 **429** + "재사용·검색·발자국·종합은 무제한" 안내. 기본은 꺼짐
  (개발/오프라인), 실LLM 배포에서 env로 켠다. 인메모리 카운터(비용 방어선이지
  지식 규칙이 아님).

## 4. 정정 재검 동선 — contested 배지 + 프로필 🔎재검 (노트 21 §3-① 완화)

- **문제(실측):** 발자국=안목 가중이라 교정 역전엔 *고안목자의 갈아타기*가
  결정적인데, 원답을 밟았던 사람은 정정이 제기된 걸 모른다.
- **수리(알고리즘 지름길 없이, 사람이 판정):**
  - 노드 뷰 `contested` — fork가 달린 답에 **⚔️ 정정 제기됨** 배지.
  - `me/stats.recheck` — *내가 밟은 길에 그 후 정정이 제기된* 목록(정정을
    아직 안 밟은 것만). 프로필에 **🔎 재검** 섹션 — 눌러 보고, 정정이 맞으면
    그쪽을 밟는다. 밟으면 목록에서 사라짐(재판단 완료).
  - 신선도 재검 넛지와 같은 패턴 — 새 메커니즘 아님.

## 5. 조건 패싯 — `conditions` (노트 18 P2 구현)

- 노드에 `conditions: list[str]`(≤6개·≤60자) + 직렬화(JSON·pgstore 컬럼 마이그레이션).
- **입력 경로에 폼 없음:** `/conditions/suggest` — AI가 본문에서 *후보만* 추출
  (상태 불변) → 칩 탭으로 확정 / ×로 제거(`/conditions`). 노트 16 릴레이션
  확인과 동형.
- 종합(synthesize) 근거 제목에 `(적용 조건: …)` 주석 — "이 답은 Pro/Max 한정"이
  종합 답에 전달된다.

## 6. 종합 근거 정렬 = 렌즈 권위 (노트 18 P0 잔여 절반)

- 근거 정렬을 스테이크 단독 → **렌즈 권위(두루·신선도 반영) 우선, 스테이크
  tie-break** 로. 신선한 교정이 낡은 원답보다 근거 상단에.

## 7. 반증 유도 (노트 18 P3 구현)

- fork 컴포저 플레이스홀더: *"왜 기존 답이 틀렸나(반례·실측·적용 조건) + 교정된
  답 — 이유가 남아야 틀린 답이 부활하지 못합니다."* (새 스키마 없음)
- fork 생성 시 원답에 **「대립」 관계를 fork 저자 명의로 기록** — 포크라는 행위
  자체가 그 사람의 판단이므로 자동-AI 확정이 아니라 *사람 행위의 기록*이다.
  (`relate`가 부모를 자연 대상으로 허용하도록 확장)

## 8. 함께 고친 것

- 레거시 테스트 2건이 *스텁 자가-링크 아티팩트*(§1이 제거한 바로 그 구멍)에
  의존하고 있었음 — 특허 의미(실재 글에 대한 선견)에 맞게 갱신.
- `me/stats` 재검 루프의 defaultdict 순회-중-변형 버그.
- 시뮬 스크립트 스냅샷 누적 오염(실행 간 상태 잔존) — 시작 시 초기화.
