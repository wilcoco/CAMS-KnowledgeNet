# 15 — 정렬: 재사용 위에 사람 (기여·판단·대안)

> 모든 논의의 수렴점. 미션(덜 쓰고 더) · D1(재사용) · D2(참여) · 두루(대안)를 *한 방향*으로.

## 한 문장
> **가장 싼 답(재사용)을, 사람이 *키우고(기여) · 가려내고(판단) · 견준다(대안)*.**
> = *가장 싸면서(AI 0)* 동시에 *가장 좋은(사람 가치)* 답.

## 비용 사다리 + 사람 4겹

하드웨어 물리: **재사용(조회) < 어떤 생성**(작은 모델조차). 그래서 *맨 싼 답 = 안 만드는 답.*
그 *재사용 위에* — **AI 비용 0으로** 사람 가치가 쌓인다:

1. **재사용(reuse)** — 기존 답을 꺼냄 (검색/공유 커먼즈, 생성 0 = 제일 쌈)
2. **+ 기여(보강)** — 사람이 *키움* → *AI 원답보다 풍부* (LLM Wiki의 평탄 합성 아님)
3. **+ 판단(발자국·채택·권위)** — *가려냄* → **신뢰(두루)**, 맹목 캐시 아님
4. **+ 대안(정정·fork)** — *견줌* → 단일 목소리 아닌 **지형**(이견 보존)

→ **2·3·4의 enrichment는 *AI 비용 0*(사람 행위).** *"덜 쓰고 더"* 의 완성:
*재사용으로 AI를 아끼고(D1), 사람이 공짜로 가치를 더한다(D2).*

## 정렬은 *새 빌드가 아니라 방향* — 네 겹 *이미 다 있다*

| 겹 | 구현 (확인됨) |
|---|---|
| 재사용 | 하이브리드 검색 · 공유 public 커먼즈 ✓ |
| 기여 | `contribute`(보강) ✓ |
| 판단 | `endorse`(발자국)·채택/권위·두루 탐침 ✓ |
| 대안 | `fork`(정정/다른 답) ✓ |

→ 할 일 = *이 네 겹을 **핵심 경험으로 전면화***. **AI 자판기가 아니라 —
*살아있는·판단된·견줄 수 있는 지식을 재사용하고, 거기 기여한다.***

## D1·D2·D3
- **D1(재사용)** = 효율 바닥. 검증됨([RouteLLM], 재사용<생성=물리). *상품화* → 차별 아님.
- **D2(기여·판단·대안)** = **해자.** 사람을 *소비자 → 기여자*. 순수 AI 제품엔 없음.
- **D3** = 기여가 *두루* 모이면 **집단지성**(혼자 인간+AI의 한계 해소).

## 미션 정렬
> **"AI를 *덜 쓰고*(재사용=생성 회피) + 사람이 *키운*(기여·판단·대안) 지식."**
> 두 차원이 한 방향. 효율(D1)은 *증거*, 참여(D2)는 *해자*, 집단(D3)은 *emergent*.

## 콜드스타트 (유일한 관문)
D2(기여)는 *해자이자 가장 어려운 것* — 사람은 기본이 *수동 소비*. → 기여가 *노동이면 죽음(야후).*
*발자국=부산물, 판단=어차피 할 사고*여야. **점화 단위 = 소그룹**(무리 안에선 기여가 자연·사회적).
