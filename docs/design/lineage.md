              · 질문→답→보강/후속/정정/포크

## 256 → 새 설계 핵심 변경점

| 축 | 256 (2005) | 새 설계 (2026) |
|----|-----------|---------------|
| 노드 | 뉴스/댓글 (사람 콘텐츠) | 인간Q + AI답 쌍 |
| 목표 | **수렴** — 하나의 순위 | **수렴 거부** — 가지치고 잠복·부활 |
| 반대 의견 | 순위에서 밀려 사라짐 | 새 가지로 분기, 죽지 않음 |
| 평가 화폐 | 링크(추천) | 기여 + 그에 건 포인트(확신) |
| 가치 실현 | 순위 노출 | 사후 배당 (동의가 모이면) |
| 해자 | 알고리즘 (특허) | **적용 도메인** (특허 만료, 알고리즘은 공공영역) |

> 알고리즘은 더 이상 해자가 아니다. 새 해자는 *무엇을 평가하느냐* — 그리고
> 그것을 **외부 현실(제조 수율·물성)에 닻 내릴 수 있느냐**다.
