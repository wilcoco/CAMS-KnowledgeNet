# 10 — 내비게이션 세션: 결정 · 로드맵 · 미결

> **상태:** 진행 기록(살아있는 문서). 이 세션의 규칙·기획 대화를 컨테이너 휘발에 대비해
> 보존한다. 코드로 들어간 결정은 노트 08·09, 이 문서는 **맥락·로드맵·미결**.

---

## 1. 이 세션에서 정한 것 (구현됨)

1. **단일 재귀 제스처(노트 08)** — slug든 드래그든 *가리키면* 그 주제로 들어간다.
   "보편 개념 / 맥락 펼침" 2분기는 폐기, 진짜 갈림길은 *읽고 끝낼까 / 더 물어 가지칠까*.
2. **좌측 IDE 트리 탐색기(노트 09)** — Root→서브 디렉토리. 클릭하면 그 노드로,
   어디를 읽든 트리가 "너 여기 있다"를 강조(위치 동기화).
3. **계위 교정(노트 09 §2.5)** — 루트 밑에 두 종류가 매달린다:
   - **보강·정정·후속질문·↳펼침** = 사람 기여, *가장 중요한 연결* → 펼쳐지는 가지(밝게).
   - **드래그/슬러그로 가리킨 개념** = 루트에서 뻗음 → **`→` 참조 잎**(흐리게, 클릭 점프).
   - 슬러그는 그래프(순환·다중부모)라 참조 잎으로만 — 무한 중첩 방지. **slug ⟂ 계위.**
   - 후속질문의 AI 답 노드는 질문 행에 **접어** 빈 행 노이즈 제거.
4. **검색 우선 레이아웃** — 좌측 맨 위 = 검색(진입). *검색으로 루트가 생기면 그 밑을
   트리로 정리한다.* 트리는 검색 아래.

## 2. 핵심 발견 — RAG는 아직 미배선 (중요)

- `ask`(AI에게 묻기)는 `_ask_ai(질문)` **맨 질문만** 보낸다. 검색결과(`related`)는
  화면에 *보여주기만* 하고 프롬프트엔 안 들어간다 → 답이 코퍼스에 근거하지 않음.
- `followup`/`unfold`는 **부모 체인**만 컨텍스트(코퍼스 전체 검색 아님).
- `보강(comment)`은 텍스트 첨부만(AI·검색 없음).
- ⇒ "기존 지식 재사용 RAG"는 *노출*이 아니라 **신규 배선** 과제.

## 3. 로드맵 (미구현 — 워크스트림)

### A. 보강의 세 갈래 + 진짜 RAG
보강할 때 사람의 실제 행동 3가지:
1. **직접 쓰기**(현행). 2. **검색해 인용·연결**(내부 노드 RAG). 3. **외부 링크**.
- **✅ 외부 링크 자동 처리(1차).** 본문 URL은 클릭 링크(↗)로 렌더(`renderText`).
  보강/정정에 URL이 있으면 **서버가 그 페이지를 fetch→본문 추출→AI 요약**해 본문에
  덧붙인다(`_summarize_url`, 단일 원천·국소 = 노트 12). **라이브 LLM+네트워크(Railway)에서만**
  실제 요약, 없으면(샌드박스) 우아하게 생략. ⚠️ URL만 프롬프트에 넣으면 *환각* — 반드시
  본문을 fetch해 근거로 줘야 진짜 요약.
- *미구현:* 내부 노드 RAG(답 생성에 `related` 근거 주입), 요약을 *별도 출처노드*로 분리.

### B. 개인 지식체계 (이미 있는 신호로 산출 가능)
1. **영역 점유율 프로필 — ✅ 1차 구현.** 우측 상단 카드 + `GET /api/me/stats`.
   세 층위: **전체**(내 저작/전체 노드 비율 + 권위 점유율=영향력), **영역별**(영역 =
   최상위 루트+서브트리, emergent — 별도 택소노미 없음), **그룹**(오버레이 안 몫 + 그룹
   안목). 숫자 클릭 → 내 노드 상세 펼침(클릭해 이동).
   - *미구현:* 지지율(내 노드가 받은 endorse 비율), 평가=저작 반영(coauthor 포함),
     링크 생성 점유율(현재는 노드 저작 기준 + 안목hub 별도 표기).
2. **로컬 내보내기 — ✅ 옵시디안 볼트(zip).** `GET /api/export?user=&space=&scope=mine|all`.
   노드 1개 = `.md` 1개(파일명=제목), 본문 `[[Title]]` 위키링크 그대로 → 옵시디안에서
   바로 연결. 프론트매터(출처·권위·저작·AI모델), `## 연결`·`## 토론`(보강/정정/후속,
   AI답은 접힘). 프로필 카드의 ⬇ 버튼. *미구현: JSON 변형, 첨부 외부링크.*
- **C와 같은 인프라:** 전역 트리/그래프에 *내 노드 하이라이트* = 점유율 가시화(다음 단계).

### C. 내비게이션 다음 단계
- **참조 잎(→) 동작:** 클릭 점프(현행) vs 그 자리 펼침 — 사용 후 결정.
- **트레일 졸업:** 링크 클릭을 우측 누적 대신 **중앙 제자리 전환 + 트리 위치**로.
- **그래프 미니맵:** 트리로 부족하면(교차링크 多) 이웃 그래프(SVG/canvas)로 승격.
- **slug 승격 표시:** 후속이 참조되면 ◆개념으로(계위 유지, 정체성만 전역 — 노트 08 emergent).

### UI 정합 감사 (결과)
- **#1 두 내비 동작은 정상** — 트리 클릭=위치 이동(텔레포트, 본문 교체), 우측 트레일=
  구조 구축 경험의 연속(체인 누적). *의도된 두 모달리티*(IDE 탐색기 클릭 vs 정의로 가기).
- **#2 상단 ask-row(`이 주제를 더 묻기`) 제거 — 후속질문을 액트바로 일원화(재귀 정합).**
  특수 위치의 ask-row는 재귀 형식을 깨는 군더더기였음. 노드든 가지든 **전부 같은
  `[보강][정정][후속질문]` 액트바**로 통일 → 묻기=후속 가지가 같은 형식으로 재귀.
  (앞선 "노드레벨 후속질문 제거"는 뒤집음 — ask-row 쪽을 없애는 게 더 일관.)
- **#3 스레드 접지 않음** — 답이 평가 단위라 펼쳐 둠(트리=개요 접기 / 스레드=상세+평가
  펼침 = 정당한 뷰 밀도 차이). 동결 AI답 라벨만 "기여"→"답".
- **#4(소싱 1급화)** = 정합이 아닌 다음 기능(액트바 `📎출처` 후보).
