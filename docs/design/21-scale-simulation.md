## 3. 실측이 새로 가르쳐준 것 3가지

### ① 교정 역전의 실제 역학 — "안목이 무게"의 이면
권위는 발자국 수가 아니라 **Σ amount×(1+밟는 이의 안목)** — 그래서:
- 신참 다수(원답 지지자 수+2명)가 교정을 밟아도 **역전 불가**.
- **고안목 1명의 갈아타기**가 결정적 (그래도 원답이 매우 인기면 1/4만 역전).
- 이는 밴드왜건 저항(늦은 유행 억제)의 *이면* = **교정 지연 비용**. 시빌 다수로
  교정을 위조할 수 없다는 점에선 옳은 설계이나, 휘발성 사례(노트 18)의 "교정이
  빨리 떠야 한다"와 긴장.
- **개선 방향(사람-중심 유지):** 알고리즘 지름길 대신, *정정이 제기되면 원답의
  기존 발자국자(특히 고안목자)에게 재검 넛지* — "당신이 밟은 길에 반례가
  제기됐습니다. 다시 보시겠어요?" 판정은 사람이, 시스템은 알림만. (신선도
  재검 넛지와 같은 패턴 — 새 메커니즘 아님.)

### ② 허브 파밍 뚫림 — 정량 확인 (최우선 무결성 수리)
흔한 개념(`[[품질]] [[안전]]…`)을 가리키는 모음글 12쪽만으로 파머 허브
**105 vs 큐레이터 중위 28** — 안목 보드를 압살. 결정로그 "미해결 2"가 *가설이
아니라 실측*이 됨. 큐레이터 top10 밀려남(2/8)의 주원인이기도 함(저자의 자동
스텁 링크도 같은 뿌리). → **수리: 스텁(빈 개념) 대상 링크는 허브 적립
제외/대폭 감액** — 스텁이 실제 글로 승격된 *뒤의* 링커부터 적립.

### ③ 스팸 생성 무방비 — 노트 19가 이론이 아님
고유 질문 100건이 전부 초안 생성됨(dedup은 동일 슬러그만). 오프라인 스텁이라
0원이지만 실LLM이면 비용 무방비. 초안은 배지로 격리되고 랭킹엔 안 오르므로
*지식 오염*은 없음 — 문제는 순수히 **비용**. → 노트 19 무료 쿼터(하루 N건)
구현이 방어선.

## 4. 개선 백로그 (실측 근거, 우선순위) — **→ 전체 구현됨(노트 22), 6번만 관찰 유지**

1. **스텁 대상 링크 허브 적립 제외/감액** — §3-② (안목 경제의 신뢰가 걸림).
2. **정정 제기 → 원답 발자국자 재검 넛지** — §3-① (교정 지연 완화, 사람이 판정).
3. **생성 쿼터(노트 19)** — §3-③ (실LLM 전환 전 필수).
4. 링 상호 허브 적립단 할인(결정로그 미해결 1) — 표적 권위는 두루가 막지만
   안목 보드 오염 벡터는 잔존.
5. 종합 근거 정렬에 신선도 가중(18-P0 잔여 절반).
6. (관찰 유지) 초안 중복 생성 18% — 초안 related 노출로 충분한지 실사용에서 재평가.

## 5. 종합

**미션 지표는 규모에서도 선다** — 재사용률 82%, 검색 1위=채택본 100%, 시빌 차단,
그룹 격리, 종합 100% 근거 표기, 신선도 신호, 부하 p95 < 20ms. **뚫린 곳은 안목
경제의 한 벡터(스텁 파밍)와 비용 게이트(쿼터)** — 둘 다 수리 방향이 이미 설계에
있고(결정로그·노트 19), 이번 실측으로 우선순위가 확정됐다.
