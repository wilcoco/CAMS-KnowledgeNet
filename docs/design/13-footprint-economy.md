# 13 — 발자국 경제 (v2 — 특허 기반 확정)

> **상태:** v2 — 기반 특허(KR 10-0913256 / 10-0952391, [`../patents/analysis.md`](../patents/analysis.md))로
> v1 초안의 미정 knob을 해소. 특허는 **만료 공개 + 발명자 본인(Json=홍정수)** — 자유 재사용.
> **한 줄:** *발자국 경제의 코어는 새 발명이 아니라 **2005년 특허의 순서가중 허브/권위
> 산술** 그 자체다 — 먼저 알아본 사람(허브)이 나중 발자국에서 **평판을 상속**받고, 저자는
> **권위**로 받는다. 화폐가 아니라 **이중 평판 통화**.*

## 1. 특허 코어 = 우리 배당 수학 (그대로)

- **청구항 1 / 수학식 10:** 노드 권위 += 발자국 가치 × **(1 + 밟는 사람의 허브)** —
  *"발자국 무게 = 밟는 사람의 안목"* 이 특허 원문이다.
- **청구항 3 (합산/상속):** *먼저* 밟은 사람의 허브 = 이후 밟는 사람들의 허브를 **계속
  상속** — v1의 "선점 배당"이 정확히 이것이고, 통화는 **돈이 아니라 허브(평판)**.
- **증분·실시간:** 반복 수렴(HITS/PageRank) 없이 링크 순서로 즉시 갱신 — **노트 12의
  점증 불변식이 2005년에 특허로 선취결정된 것.**
- **반(反)밴드왜건:** 늦게 올라타면 거의 못 번다 — 인기 편승 구조 억제가 내장.

| **391 권한** | **높은 허브 → 편집자(가려내기·병합·신뢰편집 권한), 높은 권위 → 기자(저작 신뢰)** — 점진적 신뢰 사다리의 특허 원형. |

## 3. 구현 현황 (코드 대조)

- ✅ `scoring.py` — 청구항 2(count)·3(sum)·harmonic(MVP 변형, 1/j 감쇠) 모두 구현.
  운영 기본은 `harmonic`(부드러움), `NIGHTWISH_HUB_MODE=sum`으로 청구항 3 정본 전환 가능.
- ✅ **endorse(👣) → `scoring.link(weight=1)`** 배선됨 — 발자국이 특허 엔진을 탄다.
  위키링크 생성(expand/fill)도 링크 행위로 허브 적립.
- ⬜ **자동 자기 발자국** — 저자를 *첫 링커*로 등록(청구항 1의 자연 독법: 저자가 첫
  상위노드). 노트 10의 "자기 인도스 귀찮음 제거"가 이 한 줄로 특허와 정합.
- ✅ **운영 mode 결정 = `harmonic` 유지** (2026-06 시뮬, 결정로그). sum(청구항3)은
  콜드스타트에 허브가 0으로 죽고, count는 밴드왜건 억제가 약함 — harmonic이 선견 차등·
  밴드왜건 억제·콜드스타트 균형 최선. 청구항 2·3은 코드 보존(전환 가능).

## 4. 특허 *밖* — 우리의 확장 (방어층)

특허는 정직한 포털 사용자를 가정했다. 우리는 적대 환경 가드를 *위에* 얹는다:
- **두루(독립성) 가중** — 권위를 발자국 *수*가 아니라 *독립 출처 다양성*으로 보정
  (시빌 탐침 §7 재사용). *많이가 아니라 두루.*
- **규정타석(N>n)** — 여러 노드에서 꾸준해야 허브 적립 발동(럭키 한 방·파밍 게이트).
- **정정-환수** — fork로 밀려난 답의 상속 정지(인기 ≠ 진실 교정).

## 5. 위험 (v1에서 유지)

- ⚠️ earliness ≠ truth → 정정-환수로 묶는다.
- ⚠️ 시빌 — 무료 발자국이라 더 중요. §4 + 탐침(§7) 다층으로.
- ⚠️ sum 모드의 부자-더-부자 복리 → harmonic 기본 유지 이유.

## 6. (v1에서 승계) 깔끔한 추적 예시

허브 통화로 다시 읽기 — 저자 A의 노드에 U1, U2, U3 순서로 발자국(weight 1):
```
U1 밟음: A의 노드 권위 += 1+hub(U1)          | U1 허브: 이후 상속 대기
U2 밟음: 권위 += 1+hub(U2),  U1 허브 += 상속  | (sum: hub(U2)만큼 / harmonic: 1/1)
U3 밟음: 권위 += 1+hub(U3),  U1·U2 허브 += 상속(U1이 더 큼 — 선점)
```
→ 저자는 권위로, 먼저 가려낸 U1은 허브로 — *오늘 내 발자국이 뒷사람의 길이 되고,
그 길이 나를 증명한다.*
