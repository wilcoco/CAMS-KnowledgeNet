# 13 — 발자국 경제 (초안)

> **상태:** 초안 — 룰 골격 합의, 일부 knob 미정. 아직 *구현 전 설계 탐색*.
> **한 줄:** *저자 영구 50% + 나머지 50%는 **선행 발자국 지분**에 배당 → **먼저 잘 밟은
> 사람**(안목)이 나중 발자국에서 보상받는 큐레이션 마켓. 가중치는 **track record(L/M)** 로
> 내생, **규정타석(N>n)** 통과해야 발동.*

발자국 메타포어(노트 10): 지나가며 남기는 가벼운 인도스. 그 *경제 백본*을 여기서 정의한다.
(UX는 한 클릭 👣 — 아래 배당 수학은 **뒷면**에서 안목·권위를 산출하는 용도.)

## 1. 배당 규칙

새 발자국 1개(가치 v)가 사용자 U로부터 들어올 때:
- **저자 = 0.5·v** (항상 50%, 영구).
- **나머지 0.5·v = *U 이전에* 그 노드를 밟은 사람들에게, 보유 지분 비례 배당.**
- **선행자 없으면 전부 저자.**
- U는 **보유 지분 +(발자국×w_U)** — *이후* 들어올 발자국에서 배당받음(자기 발자국에선 못 받음).
- **재투자 허용**: 같은 노드 추가 발자국 가능. 단 *자기 새 발자국은 자기 기존 지분에 배당하지 않음*(자기거래 방지).

깔끔한 추적(저자 A, v=1, w=1 가정):
```
fp#1 (U1): A 1.0 (선행자 없음)            | 지분 U1=1
fp#2 (U2): A 0.5 · U1 0.5                 | U1=1, U2=1
fp#3 (U3): A 0.5 · U1 0.25 U2 0.25        | U1=1, U2=1, U3=1
fp#4 (U2): A 0.5 · (U1,U2,U3) 각 1/6      | U2=2 …
```
→ 가장 먼저 밟은 U1 누적 배당 최대(=선점/안목 보상). 저자는 총량의 50% 수렴.

## 2. 발자국 가중치 w — track record + 규정타석

사용자 u: **M=누적 투자 발자국**, **L=누적 수령 배당**, **N=발자국 남긴 서로 다른 노드 수**.
```
ρ_u = L_u / M_u                          # 발자국당 수익률(안목·행태 지표)
w_u = 1                                  (N ≤ n  — 규정타석 미달: 기본)
    = clamp( (ρ_u/ρ̄)^α , lo, hi )        (N > n  — 충족: 안목 발동)
```
- **규정타석 N>n**(야구 규정타석): *여러 노드에서 꾸준히* 잘해야 가중치 발동 → 럭키 한 방·소표본 차단.
- ρ̄ = 모집단 ρ 중앙값. **α∈(0,1] 오목 + clamp(lo,hi)** → 부자-더-부자(runaway) 댐핑.
- 신규/미달 = **w 1**(중립).
- 지분 = **Σ(발자국 × w_u)**, 배당은 지분 비례.

## 3. 가드레일

- **정정-환수(진실 결합)** — 정정(fork)으로 *밀려난* 답의 발자국 배당은 정지/환수.
  ("인기·선점 예측 ≠ 진실"의 Steemit 함정 교정.)
- **오목 α·clamp** — 가중치 폭주 억제.
- **저자 50% 감쇠**(옵션, 미정) — 후기 정제자 보호.

## 4. 위험 (객관)

- ⚠️ **earliness/popularity ≠ truth** — ρ는 *선점·인기예측*을 보상. → 정정-환수로 묶어야.
- ⚠️ **L/M 시빌 파밍** — 발자국이 *무료*면 패거리가 나중 발자국을 몰아 L 제조 → w 인위 상승.
  규정타석이 문턱은 높이나 작정한 링은 N>n 도달 가능 → **#5(비용/신원)가 결정타.**
- ⚠️ **재금융화** — 배당 캡테이블이 가벼운 발자국 UX를 다시 무겁게. → 수학은 *뒷면*, UX는 *한 클릭*.

## 5. 미정 knob (정하면 수식·예시 확정)

- **#5 (결정타) 발자국 = 무료(평판) vs 비용(스테이크)?** + 신원. *추천: 작은 비용 + 약한 신원.*
- **f 파라미터:** n(규정타석), α(오목), lo/hi(상·하한), ρ̄ 산정(중앙값/이동평균).
- **저자 50% 영구 vs 감쇠.**
- **배당 단위:** 평판 점수인가, 전환가능 포인트인가.

## 6. 기존 모델과의 관계

이 메커니즘은 **안목(hub)·권위(authority)** (노트 02·03)를 *배당 수학으로 내생화*한 것.
현재 `/api/endorse`의 payout 규칙을 이 규칙으로 대체/정련하는 방향. **노트 12 불변식**(증분·
국소·전역패스 없음) 준수: 배당은 발자국 인플로우마다 *국소*로 정산, 가중치는 증분 갱신.
