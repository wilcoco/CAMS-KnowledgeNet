# 17 — 평가 동기와 게이미피케이션: 드러내되, 만들지 않는다

> **상태:** 검토 → 결정. 전제: 노트 13(발자국 경제)·15(정렬)·00(답설야중거).
> **한 줄:** *게임은 이미 우리 안에 있다 — 발자국=베팅, 뒤따르는 발자국=검증, 허브
> 상속=지연·가변 보상. 게임화 = 포인트를 **추가**하는 게 아니라 이 루프를 **드러내는** 것.*

## 1. 핵심 발견

특허 경제가 이미 완전한 게임 루프다(가변비율·지연 보상 — 가장 강한 보상 구조):
```
발자국(베팅: 이 답이 진짜 길이다) → 남들이 따라 밟음(검증) → 허브 상속(보상)
```
그런데 현재 UI는 **"검증되는 순간"** — 내 이른 발자국이 맞았다고 판명되는, 진짜 동기의
순간 — 을 전혀 보여주지 않는다. 그래서 할 일은 보상 발명이 아니라 **결과 가시화**.

## 2. 문제 (P1~P7)

| # | 문제 | 우리 맥락 |
|---|---|---|
| P1 | 밀어내기(crowding-out) — 외재 보상이 내재 동기 파괴 | Steemit의 사인. "금융 뒤로" 결정을 게임화가 되돌릴 위험 |
| P2 | 굿하트/파밍 — 점수가 목표가 되면 점수만 좇음 | 재미↑ = 파밍 유인↑. S4 시뮬: 산식은 시빌≡독립 |
| P3 | 노동화 — 퀘스트·스트릭=판단이 숙제 | 야후 함정 재림. "발자국=부산물" 붕괴 |
| P4 | 톤 충돌 — 유치한 게임색 ↔ 신뢰 지식 브랜드 | 눈밭·길의 절제된 톤 유지 |
| P5 | 루프가 늦게 닫힘 — 검증은 남이 와야 발생 | 초기·솔로엔 보상 이벤트 부재(콜드스타트 동형) |
| P6 | 품질 vs 속도 — 빨리 밟게 하면 판단의 질↓ | 가려내기 가치 자체 훼손 |
| P7 | 리더보드 부작용 — 전역 순위=신규 좌절·파밍 표적 | 우측 패널이 사실 전역 보드 3개 |

## 3. 해법 — 원칙: 보상을 발명하지 말고, 이미 있는 *결과*를 보여줘라

1. **검증 이벤트** ★ — "당신이 2번째로 밟은 길이 🔥두루 밟힌 길이 됐습니다." 새 메커니즘
   0(허브 상속이 이미 계산), *표시만*. 유능감 피드백 = P1 안전.
2. **n번째 발견자** — 패널에 "당신은 이 길의 k번째 발견자" + 발자국을 *순서대로*.
   순서가 자산임을 보드처럼 보이게.
3. **결과 가시화** — 점수 말고 영향: "당신 발자국 이후 7명이 따라 걸음".
4. **서사적 마일스톤** — 배지=교환 불가 이력(첫 발견자/길을 바로잡음/개척자). 통화 아님.
5. **규정타석 = 언락** — N>n에서 안목 공개 활성화. 시빌 게이트가 곧 진행 장치(일석이조).
6. **리더보드는 국소·상대** — 내 그룹/이 영역/이번 주(신규도 이길 수 있는 판).
7. **솔로 단계 = 내 지도의 성장** — 검증 이벤트 없는 초기엔 내 영역 트리 성장이 피드백.

## 4. 금지선 (명시)

❌ 발자국 바운티/포인트 지급 ❌ 스트릭·일일퀘스트 ❌ 전역 단일 리더보드 강화
❌ 밟기 속도·수량 보상 ❌ 유치한 장식 — (P1·P2·P3·P7·P4 각각의 직격 원인)

## 5. 선행 조건 — 두루 집계 (로드맵 ③)

검증이 *진짜*여야 게임이 선다 — 패거리 5명이 따라 밟은 걸 "검증"으로 울리면 파밍
게임이 된다. → **권위에 독립-출처 가중(두루)** 이 게이미피케이션의 토대.
구현: 읽기시점 렌즈 — `authority_in`에 **다양성 보정** ×(유효 독립 출처/원시 수),
한 클러스터 = √n 표(부드러운 시작). 클러스터 = 탐침 로직 재사용(희소노드 공동출현
≥2 + IDF-코사인, 클럭당 메모). *한계(정직): 읽기시점 할인은 권위 표시를 누르지만,
결탁 내부의 허브 상속 적립 자체는 아직 안 누름 — 그건 §13.7 3단계(적립 할인)의 몫.*
