# 24 — 잔여 백로그 완결: BYOK · 자동 자기발자국 · 유효 재확인

> 노트 23 §4와 노트 20 §3에 남아 있던 코드 백로그를 전부 구현. 이로써 설계
> 노트들(13·18·19·20·21·22·23)의 **결정-미구현 항목이 0**이 된다. 테스트 170.

## 1. BYOK-lite (노트 19 ③ 후반)

- **동선:** 무료 생성 쿼터 소진(429) → *"재사용·검색·종합은 계속 무제한!
  계속 생성하려면 본인 Anthropic API 키를"* → 키 입력 → 즉시 재시도.
- **보안 경계:** 키는 **브라우저 localStorage에만** 저장, 서버는 그 요청의
  생성 1회에만 사용하고 **저장하지 않는다**(회귀 테스트: 스냅샷에 키 부재).
- 구현: `AskBody.api_key` → `_ask_ai_byok`(키 1회 사용, `llm.claude_draft(api_key=)`) —
  BYOK 생성은 쿼터 미차감(본인 비용).

## 2. 자동 자기발자국 (노트 13 잔여 해소)

- **결정 원문:** *"자기 것 인도스는 귀찮아 할 것 → 가중치 1로 자동 인도스."*
- **구현:** *사람이 만든* 기여(페이지·보강·정정·사람 답변)는 저자가 **첫
  발자국(가중 1)** 으로 자동 기록. **AI 초안엔 없음** — 질문자는 재료를
  띄웠을 뿐(보상 위계: 사람 실질 기여 > 평가 > AI 초안, 결정로그 §6).
- **효과:** 뒤에 남이 따라 밟으면 저자의 안목(허브)이 자동 검증 — 정정자가
  옳았을 때 안목 보상이 사람 손 없이 흐른다. 채택(스테이크)은 불변 —
  자기발자국으로 자기 답을 '채택'시킬 수는 없다.

## 3. "아직 유효함" 재확인 (노트 20 §3-6 저울질 완료)

- 재검 넛지에 **✅ 아직 유효함** 버튼 — 탭 한 번 = 사람의 재검 판정,
  신선도 시계 리셋(`/api/nodes/{id}/reconfirm`). 노동화가 아니라 *한 번의
  판정*이므로 금지선(노트 17)과 충돌하지 않는다고 판단. 폐기는 여전히
  정정(fork)으로만 — 자동 폐기 없음.

## 4. 모바일 사다리 압축 (노트 23 잔여)

- ≤880px: 버튼 줄바꿈 허용, 배지·메타 축소 — 계단(재사용→종합→생성)은 유지.

## 5. 검증

- 테스트 **170개**(신규 3: 자기발자국이 사람 저작에만 / 재확인 시계 리셋 /
  BYOK 쿼터 우회 + 서버 무저장) 통과.
- 시뮬 재실행: 11개 페르소나 판정 불변(10 ✅ · 정정자 ⚠️=설계 귀결).

## 6. 이제 코드 백로그는 비었다 — 남은 것은 하나

- ⏸ 조건 패싯 검색 필터화 — *의도적 보류 유지*(데이터 쌓인 뒤, 노트 18).
- 관찰 항목: 정정 역전율(재검 동선 실효)·초안 중복 생성 18%.
- **다음 한 걸음은 기능이 아니라 실사용이다** — 실제 소그룹 한 바퀴
  (질문 10개·발자국·정정 1건이면 충분, 노트 20 §3-1). Railway 배포 시
  `NIGHTWISH_ENABLE_LLM=1` + `ANTHROPIC_API_KEY` + `NIGHTWISH_ASK_QUOTA=30`
  + (선택) `NIGHTWISH_CHEAP_MODEL`이면 사다리 전체가 실LLM으로 돈다.
