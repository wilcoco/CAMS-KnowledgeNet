# 구조에서 이어지는 질문과 사람의 지식

## 목적

AI 답변의 개념·관계를 사람이 검토하고 발전시킬 수 있는 참여 단위로 만든다.
문장을 읽은 뒤 무엇을 물을지, 어디에 경험을 보탤지 찾도록 돕는다.
AI의 제안, 원문의 근거, 사람이 보탠 조건과 경험은 출처를 구별해 남긴다.

## 이번 구현의 사용자 흐름

1. 질문과 선택한 내부 지식, 선택적으로 입력한 배경으로 답변을 만든다.
   공용 공간에서는 화면의 웹 검색 선택에 따라 질문의 원문 자료도 찾는다.
   그룹 질문, 내부 지식, 배경은 외부 검색어로 보내지 않는다.
2. 처음 답변을 작성할 때부터 의도·조건·개념 간 관계를 고려한다.
   답변 작성과 구조 출력의 예산을 분리해 답변을 충분히 설명한다.
   이후 완성된 답변을 바꾸지 않고 근거 구절이 있는 개념 지도를 구성한다.
3. 지도에서 개념, 관계선, 관계 목록 중 하나를 선택한다.
   원문 구절, AI 제안이라는 상태, 해당 부분에 쌓인 사람의 참여를 확인한다.
4. 네 가지 방식으로 이어간다.
   - 이어 묻기: 선택한 부분의 조건과 예외를 묻는 시작 문장을 수정해서 질문한다.
   - 근거 보태기: 자료·출처·관찰을 남긴다.
   - 조건 보태기: 적용되는 상황과 한계를 남긴다.
   - 다른 경험·반례: 다른 결과가 나온 경험과 당시 상황을 남긴다.
5. 기여는 기존 대화에도 표시되고 해당 개념·관계의 참여 목록에서도 찾을 수 있다.
   후속 질문은 선택한 구조와 거기에 연결된, 현재 공간에서 볼 수 있는 사람의
   기여 최근 5건을 참고한다. 관련 없는 다른 개념의 댓글은 자동으로 넣지 않는다.

## 저장과 의미

- 서버가 실제 지도에서 대상의 이름과 근거 구절을 찾아 저장한다.
  대상 종류·ID·지도 버전 해시·원래 답변 ID·참여 목적·당시 구절을 기록한다.
- 기존 `knowledge` JSON 저장을 사용한다. 사람의 기여에는 `contribution_target`,
  후속 AI 답변에는 선택 맥락 `focus`를 저장한다. 기존 문서와 호환된다.
- 오래된 화면이 바뀐 지도에 의견을 잘못 연결하지 않도록 버전 불일치는 거절한다.
  이미 저장된 의견은 원문이 바뀌어도 당시의 대상을 보존한다.
- 참여 건수는 활동 표시다. 진실·합의·공식 승인 점수로 해석하지 않는다.
  반례 하나가 자동으로 전체 답변을 거짓으로 판정하지 않는다.
- 기존 투자·평가와 사람–노드 가중치 계산은 변경하지 않는다.
- AI가 원문과 맞지 않는 그래프 항목을 만들면 제외한다. 지도 생성에 실패해도
  완성된 답변은 저장하며 실패 사실을 표시한다.

## 검증 범위와 다음 단계

자동 검증: 대상 위조·오래된 지도 차단, 공간별 노출, 저장 왕복, 후속 질문의
정확한 대상과 관련 기여 전달, AI 지도와 사람 참여의 구분, 기존 기능 회귀.
브라우저 검증: 네 가지 참여, 관계선 선택, 재조회, 대화로 이동, 모바일 화면.

이번 구현은 사람이 구조에 지식을 붙이는 첫 단계다. 사람의 의견을 검토해서
공식 관계를 변경하는 절차, 기여 단위의 투자 배분, 조직별 승인 권한은 별도 설계가
필요하다. 기존 서비스의 그룹 이름에 의한 공간 구분은 회원 자격 검증을 대신하지 않는다.
