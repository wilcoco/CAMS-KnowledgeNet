# 관련 연구 / 외부 관점 대조 (Related Work)

> 외부의 독립적 관점을 우리 설계와 대조해, **일치점·차이점·우리가 메울 빈틈**을
> 기록한다. 우리 결론을 강화하거나 반증하는 외부 신호를 수집하는 자리.

---

## RW-1. "지식그래프는 검색 기술이 아니다" — sanguinekim (LinkedIn, 2026)

**출처:** LinkedIn 게시글 (작성자 sanguinekim). 본 환경에서 직접 페치 불가(네트워크
제약) → 사용자가 2026-06 본문 전체를 붙여넣어 기록함.

### 글의 핵심 논지
- 지식그래프(KG)를 Graph DB·RDF·Cypher/SPARQL 같은 *기술 키워드*로 보는 건 본질을
  놓친 것. **본질 = AI가 따라갈 수 있는 "관계의 길"을 만드는 것.**
- 벡터 검색(RAG)만으로는 실무 질문(엔티티·관계·속성·출처·최신성·권한이 함께 움직이는
  질문)을 못 푼다.
- KG는 **5단계 성숙도**로 봐야 한다:
  1. **기초 모델링** — 엔티티·관계·속성·출처·스키마·온톨로지. 핵심 질문 = *"무엇을
     노드로 볼 것인가"*.
  2. **구조화** — 엔티티/관계 추출 + **같은 대상의 ID 정규화(entity resolution)** +
     provenance 보존(없으면 답 검증 불가).
  3. **검색과 탐색** — 벡터만이 아니라 **그래프 탐색 + 하이브리드.** "비슷한 문서"가
     아니라 **"연결된 근거"** 를 찾음.
  4. **AI 응용** — GraphRAG·에이전트 메모리·컨텍스트 조립·툴 라우팅·근거 답변.
  5. **운영 거버넌스** — 권한 필터·최신성 갱신·평가/관측·감사 로그·**신뢰도 점수**.
- 결론: 경쟁력은 모델 성능이 아니라 **"누가 지식·관계·맥락·운영규칙 구조를 더 잘
  설계하느냐"**. KG는 "검색의 고급 옵션"이 아니라 **에이전트가 조직 안에서 일하기 위한
  관계 지도**다.

### 우리와 같은 DNA
| 글 | 본 시스템 |
|---|---|
| 지식그래프 ≠ 검색; 본질은 관계의 길 | AI ≠ 검색, 인덱스 ≠ 인텔리전스 (§1) |
| 핵심 질문 = "무엇을 노드로 볼 것인가" | 답: **노드 = 인간Q + AI답 쌍** |
| 출처/provenance 없으면 검증 불가 | 노드의 작성자·스테이킹·(P2P 시)서명 = provenance |
| "비슷한 문서"가 아닌 "연결된 근거" | RAG 답변처를 웹 → 검증된 온톨로지로 |
| 신뢰도 점수 | 허브/권위 지수 (특허 10-0913256) |
| "왜 그 근거를 따라갔는지" 설명 구조 | 포크/계승/링크순서 계보 = 설명 경로 |
| 모델이 아니라 구조 설계가 경쟁력 | 해자는 알고리즘이 아니라 적용 도메인/구조 |

### 결정적 차이 (우리가 더 나간 곳)
- 글은 **기업 내부·인프라 관점** — "조직이 KG를 구축한다"고 암묵 가정하나 *누가·왜
  만드나*엔 답이 없음.
- 본 시스템은 그 빈칸을 채움:
  - **구축을 시장으로** — 포인트·배당으로 사람들이 스스로 온톨로지화·검증.
  - **수렴 거부** — 단일 진실 정규화 대신 포크·잠복·부활(갈릴레오 문제).
  - **외부 현실 닻 + P2P 상호증명** — 행정적 신뢰가 아니라 수율/물성·서명으로 앵커링.
- 한 줄: 글 = *무엇을(구조)*, 우리 = *왜·누가 만드나(유인) + 어떻게 안 썩나(현실·증명)*.
  **경쟁이 아니라 보완** — 글이 묘사한 구조가 곧 우리 경제의 산출물.

### 이 글이 비춘 우리 빈틈 → 액션 (로드맵 P2-KG로 반영)
| 글의 단계 | 우리 현황 | 보완 |
|---|---|---|
| 2. 엔티티 정규화 ("같은 고객 여러 이름") | ❌ 없음 (노드는 Q&A 쌍) | **entity resolution** — 같은 개념=하나의 ID |
| 3. 그래프 탐색 / 연결된 근거 | ⚠️ 단순 부분일치(`service._search`) | 트리 위 **그래프 탐색 + 하이브리드 검색** |
| 5. 권한 필터 | ❌ 노드별 접근제어 없음 | **권한/소유 경계** — §7.2 "카토 지식=영업비밀 경계"의 구체화 |
| 설명 경로 | 계보로 암묵 존재 | "근거 경로 + 보증자 + 검증여부" **명시 뷰** |
