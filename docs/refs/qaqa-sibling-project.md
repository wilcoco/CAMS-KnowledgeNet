# 참조 — 형제 프로젝트 QAQA (아이디어 소스)

> **출처:** `wilcoco/QAQA` (같은 팀의 유사 프로젝트). 컨테이너 네트워크 차단으로
> 직접 못 읽어, 공유받은 기획서 2건을 보존용으로 정리.
>
> ⚠️ **주의:** *같은 팀*이라 QAQA와 Nightwish의 생각이 겹치는 건 **독립적 검증이
> 아니다**(같은 사람들의 같은 발상). 방향성의 증거로 쓰지 말 것 — **아이디어 참조원**
> 으로만.

QAQA 한 줄: **"AI를 소비 → AI를 *키우는* 플랫폼"**, Notion급 편집 경험 위에 협업·경제.
구조: TopicCluster(폴더) → QASet(대화) → Message(Q&A턴) → OpinionNode(의견).

## 문서 A — Phase 0: 지식 구조화 (개인 우선)

> 원칙: *협업/보상 이전에, 개인이 지식을 체계화하는 도구가 우수해야 한다.*
> (= 개인 먼저 → 협업 → 경제)

**블록 기반 UI** ("Railway식 블록 에디터"): 모든 지식을 드래그 가능한 블록으로.
- 블록 타입: 질문·AI답·인간답·인사이트·의견·참조링크·폴더·**합성(AI요약)**.
- 인터랙션: 드래그앤드롭, 연결선 그리기, 호버 퀵액션, 우클릭 컨텍스트메뉴,
  인라인 편집, **슬래시 명령(/)**, **캔버스 줌아웃 전체맵**, 애니메이션, 단축키, 모바일 제스처.

**Phase 0 세부:**
- **0.1 계층형 구조** — 주제>하위주제>질문>답 폴더 트리. `KnowledgeNode`(parentId, orderIndex,
  nodeType=folder|qaset|note|link). 사용자가 *의도적으로* 폴더링(Tab/Shift-Tab).
- **0.2 양방향 링크** — `[[링크]]` + 백링크 역참조 패널. `KnowledgeLink`(source/target).
- **0.3 지식 병합(Merge)** — 유사 QASet을 AI추천→사람확정으로 통합. 정식(canonical)/
  흡수(absorbed) 상태, **발자국 합산**, 원본 보존.
- **0.4 합성 뷰(Synthesis)** ★ — 클러스터별 AI 요약: *핵심원칙 / 자주하는실수 /
  커뮤니티합의 / 논쟁 중 / 지식 갭*. 파생·캐시·버전드, 변경 시 트리거 갱신.
- **0.5 인라인 참조** — 작성 중 관련 지식 자동 제안(작성자용 내부 RAG).
- **0.6 정식 답변(Canonical)** — 여러 답 중 하나를 자동추천(발자국+도움됨%)/투표/소유자지정.

성공지표 예: 폴더 깊이 1→2-3, [[링크]] 사용률 30%+, 병합 15%+, 정식답변 50%+.

## 문서 B — Phase 1~5: 피드백·협업·경제

> 비전: AI 답을 수동 소비가 아니라, 인간 지능이 더해져 AI·사람 모두 똑똑해지는 구조.
> 이미 구현: 사람답변·AI개선·발자국 투자·반대발자국(사냥)·의견·인사이트감지·인간지식→AI주입.

- **P1 피드백 루프 — 인용 추적(Citation Tracking).** 내 지식이 다른 대화에 인용되면
  알림+보상. `Citation`(source/target, similarity, wasHelpful, reward). 알림:
  citation_received/helpful/milestone. AI응답에 *커뮤니티 인사이트 출처* 표시 + [도움됨?].
  **기여 임팩트 대시보드**(`UserImpactStats`): 인사이트/개선/인용/조회, 최고기여, AI품질기여%.
- **P2 협업 편집.** **제안 시스템**(`EditSuggestion`+`SuggestionVote`): 비소유자가 개선
  제안→커뮤니티 투표→소유자 검토/수락. **점진적 신뢰 사다리**(`collaborationType`):
  owner_only → suggestion_only → trusted_edit(신뢰도 3+) → open_edit(위키). `EditHistory`(롤백).
- **P3 토론 구조.** **스레드형 의견**(parentOpinionId 대댓글) + **입장 태그**(agree/disagree/
  neutral/question) + 투표(`OpinionVote`: upvote/downvote/insightful/needs_evidence) +
  **AI 합의 요약**(합의된 점 / 논쟁 중 / 추가 검증 필요).
- **P4 AI 학습 가시화.** "AI 지식 저장소"(사람 기여가 AI 지식으로 쌓이는 뷰), **실시간 AI
  참조 표시**(생성 중 어떤 인간지식 참조하는지), **주제별 AI 품질 점수**(`TopicAIQuality`:
  baseline vs current, "커뮤니티가 AI를 66% 똑똑하게", 최고기여자).
- **P5 선순환 경제.** 인용 보상 자동화, **지식 농장**(게임화: 새싹→싹틈→성장→결실→거목,
  인용 쌓이면 "자라고" 발자국 수확).

핵심원칙: *가시성 우선*(백엔드 기능도 UX로 드러나야), 즉각 피드백, 공정한 귀속,
점진적 신뢰, 게임화 but 본질 유지.

## Nightwish가 참조할 후보 (커밋 아님, 검토용)

- **합성 뷰(0.4)** — 노트 12가 "공짜로 안 준다"던 *단일 요약*을 *파생·캐시 뷰*로 지불하는
  방식. 논쟁중=fork, 지식갭=열린질의에 매핑. (전역 일관성 유지 없이.)
- **체감 피드백 루프(P1)** — 우리 백링크엔 없는 *인용 이벤트·알림·임팩트 대시보드*.
- **"AI 키움" 서사(P4)** — 내재 동기 엔진(우리에게 없는 서사).
- **점진적 신뢰 사다리(P2)** — 우리 hub/권위 게이팅의 구체적 거버넌스.
- **블록 에디터 UX / 명시적 폴더(0.1)** — 우리 약점인 편집 완성도.
- **합의 요약(P3)** — fork/열린질의 위 토론 합의 시각화.

## 참조 시 경계할 점

- **보상 게임화 과다** — QAQA는 +발자국 바운티·배지·지식농장을 *앞세움*. 이 세션 결론은
  *내재동기(평판·이타·AI키움) 앞, 금융/게임화 뒤*(Steemit식 crowding-out 경계). → 흡수하되
  *프레이밍은 뒤집어서.*
- **소프트 지표** — "AI 품질 +66%", 유사도 기반 인용 자동귀속은 게이밍·환각 위험(프록시로만).
- **노트 12** — Citation/품질/임팩트 집계는 *증분·캐시*(전역 패스 금지). QAQA도 롤업
  테이블(`lastCalculatedAt`)로 방향은 맞음.
