# 질문·답변과 함께 남는 개념 지도

기존 운영 화면의 세 영역을 유지한다.

- 왼쪽: 기존 지식 검색, Google 검색으로 이동, 참고할 자료 선택, 선택 자료의 당시 발췌.
- 가운데: 질문·답변, 사람의 보강·정정, 후속 질문.
- 오른쪽: 개념·관계 지도와 기존 답의 연결 지도 전환.

좁은 화면에서는 검색·자료 / 질문·답변 / 개념·그래프 탭으로 전환한다.
Google 링크는 새 탭에서 검색하며 검색 결과 수집 API를 연동한 것은 아니다.

## 생성 및 검토

새 질문과 후속 질문은 `with_knowledge: true`로 기존 API를 호출한다.
새 질문의 검색 결과는 후보 목록이며 AI에 자동 전달하지 않는다. 사용자가
‘답변에 참고’로 선택한 `source_ids`(최대 5개)만 서버에서 접근 권한과 본문을
확인한 후 전달한다. 선택이 없으면 질문만 전달한다. 질문·공간 변경 시 선택을
초기화한다. 후속 질문은 앞선 대화만 맥락으로 전달한다.
자료의 `selection` 및 지도의 `source_mode`로 선택 자료/이전 대화/자료 없음을
구별하며, 이전 버전의 자동 검색 자료도 화면에서 그 경위를 명시한다.
LLM에 처음부터 질문의 의도·조건·미확인 사항을 해석하고, 답변과 개념·관계를
같은 구조화 응답으로 작성하도록 지시한다. 완성된 답을 별도 호출로 추출하지 않는다.
검색은 입력된 질문으로 먼저 수행한다. AI가 도출한 개념을 검색어 확장에 쓰는
별도의 사전 추론 단계는 이번 구현에 포함하지 않는다.

관계 타입: is_a, part_of, requires, influences, contradicts, related_to.
개념에는 출처(question/answer), 관계에는 출처(question/answer/source)와 원문
구절이 있다. 서버는 스키마·개념 ID·출처 ID·원문 구절의 일치를 검증한다.
이는 사실 검증이 아니다. 질문의 가정과 AI의 제안을 사람의 합의로 취급하지 않는다.
모든 지도는 `ai_proposed`이며 기존의 사람 확인 관계(`link_rels`)나 평가 점수,
투자 잔액에 자동으로 반영하지 않는다. 사람→답의 투자 관계와 개념 간 관계는 별개다.

개념을 누르면 원문이 강조되고 같은 개념 검색·후속 질문으로 이어진다.
관계를 누르면 방향·관계 이름·출처 구절을 확인할 수 있다.
사람의 경험과 의견은 기존 보강·정정 경로에 원문으로 남는다.

## 저장과 호환성

`Node.knowledge`에 버전 1 JSON과 생성 모델, 질문 원문, 개념·관계 및 참고 자료
발췌·작성자·수정 시점을 저장한다. 참고 문서를 나중에 편집해도 당시 발췌는 남는다.
Postgres `node.knowledge` text 컬럼은 멱등 ALTER로 추가한다. 기존 노드는 빈
지도를 가지며 원래 연결 지도를 계속 보여준다. 기존 API 클라이언트는 그대로 동작한다.
후속 질문의 지도는 새 AI 답에 귀속되며 스레드의 ‘이 답의 개념 지도 보기’로 연다.
`/?node=<URL-encoded id>`로 답을 바로 열 수 있다.

AI 실패·불완전 응답·응답 스키마 검증 실패 시 새 답을 저장하지 않고 502/503을 반환하며
이 경로의 생성 쿼터를 돌려준다. 오프라인 스텁을 실제 답으로 저장하지 않는다.
단, 유효한 답변 안에서 일부 개념/관계의 근거 구절·출처·연결이 틀리면 해당 항목만
제외한다. 나머지 지도와 답변은 저장하고, 제외 개수와 이유를 화면에 표시한다.
키는 기존 환경변수/BYOK를 사용하며 지도·로그에 저장하지 않는다.
`NIGHTWISH_MAP_MODEL`로 지도 생성 모델을 재정의할 수 있다. 기본은 기존
`NIGHTWISH_LLM_MODEL` 설정이며 Anthropic SDK 1.0 이상이 필요하다.

자료 선택에는 기존 공간 가시성 필터를 적용한다. 그룹 멤버십/소셜 로그인 체계를
이번 지도 기능이 새로 구현하거나 보안 경계로 보완한 것은 아니다.

## 검증

`tests/test_knowledge.py`는 근거 위조·잘못된 관계·허용되지 않은 출처 거부,
공개 질문에 비공개 자료 미포함, 재시작/SQL 매핑 후 지도 보존, 자료 편집 후
발췌 보존, 실패 시 저장 없음/쿼터 반환, 후속 질문 지도와 모델 호출 계약을 확인한다.
