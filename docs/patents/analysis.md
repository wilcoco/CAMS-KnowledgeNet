### 독립항(청구항 1) 골자
- 상위노드의 **중요정보링크지수(=허브지수)** = 해당 상위노드가 **하위노드에 링크한 순서**에 따라 결정
- 하위노드의 **중요도(=권위지수)** = 그 하위노드를 링크하는 상위노드들의 중요정보링크지수 **합**
- 신규 하위노드에 복수 상위노드가 링크할 때마다 **실시간 갱신**

### 종속항
- **청구항 2 — 카운트 방식:** 이후 다른 상위노드가 링크될 때마다 허브지수 +1
- **청구항 3 — 합산(상속) 방식:** 먼저 링크한 상위노드가 이후 링크되는 상위노드들의 허브지수를 누적 합산
- 청구항 5·6·7: 하위노드 = 뉴스기사 / 상위노드 = 추천·댓글로 한정
- 청구항 8: 복수 하위노드별 지수의 평균으로 산출

## 3. 설계 문서 대조 검증

### 정확히 확인된 것
- 발명자 **홍정수**, 출원인 **SK커뮤니케이션즈**, **동일 출원일 2005-04-14**, 출원번호 **0031125 / 0031126 연번** → "형제 특허" 서술 정확
- **256 = 순수 방법특허(코어), 391 = 응용시스템** → IPC도 H04L vs G06Q로 분리. 정확
- **"반복연산 → 시간순서 치환"** → 명세서가 클라인버그/페이지랭크의 반복연산 수렴 문제를 명시하고 링크 순서 가중 + 증분 실시간 갱신으로 해결한다고 서술. 정확
- **허브지수 = 안목(먼저 알아본 능력) / 권위지수 = 콘텐츠 가치** → "좋은 기사를 가장 먼저 추천한 허브가 가장 높은 허브지수" 문구로 확인
- **편집자/기자 권한** → 391 [0114], 256 명세서 <88>에 존재

### 정정·주의
1. **법적상태 — 확정(발명자 본인 확인, 2026-05).** 두 특허는 **만료된 공개 특허**이며,
   본 시스템의 설계자 **Json = 발명자 홍정수 본인**이다. 따라서 알고리즘은 **공공영역
   (public domain)** 에 있어 자유 재사용 가능하고, 출처·권리 귀속 다툼의 여지가 없다.
   (등록공보 자체엔 소멸일이 표기되지 않으나, 발명자 본인 확인으로 빈칸이 닫혔다.
   필요 시 KIPRIS 행정처리이력으로 소멸일만 문서화하면 됨 — 권리 판단에는 영향 없음.)
2. 256 청구항은 **총 7항(4번 삭제)** 로, 코어 권리가 방법항 위주로 비교적 좁게 한정됨.
   (만료된 지금은 권리 범위와 무관하게 전체를 자유 재사용 가능 — 참고용 기록.)

## 4. 새 설계와의 권리 관계

- 청구항 3의 **합산(상속) 방식**이 새 설계의 **"시간가중 계승·배당"** 과 1:1로 대응한다.
- **만료된 공개 특허 + 발명자 본인**이므로 이 메커니즘은 **제약 없이 자유 재사용**한다.
  (공공영역이라 타인도 사용 가능하다는 점은 곧 *알고리즘은 더 이상 독점 해자가 아님*을 뜻함.)
- 따라서 해자는 알고리즘이 아니라 **적용 도메인(검증 가능한 제조 현실)** 으로 이동한다는
  설계 결론과 정합적. 실제 구현(`src/nightwish/scoring.py`)은 청구항 2·3을 그대로 코드화했다.
